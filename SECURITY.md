# Security Policy

Tai Audit Skill is an audit workflow assistant. It may generate incorrect or incomplete findings and should not be treated as a substitute for manual review.

## Reporting Security Issues

For security issues in this repository, open a private advisory or contact the maintainers through the repository owner.

Do not include private keys, exploit targets, or non-public client code in public issues.

## Dependency Boundary

`x-ray` is supplied by upstream `pashov/skills`. Security reports about x-ray itself should be directed to that upstream project unless the issue is caused by Tai's integration instructions or installer.
